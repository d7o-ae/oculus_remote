# Gear Remote

يحوّل ريموت Samsung Gear VR (SM-R323 / R324 / R325) إلى ريموت لجوالك: تقليب الريلز، الصوت، الرجوع.

## طريقة البناء (بدون تثبيت Android SDK) — عن طريق GitHub
1. سوِّ حساب على github.com إذا ما عندك، وبعدها **New repository** (خلّه Private).
2. ارفع محتوى هذا المجلد كامل (بما فيه مجلد `.github`).
   - من VS Code: افتح المجلد ← Source Control ← **Publish to GitHub**.
3. ادخل على الريبو ← تبويب **Actions** ← بيشتغل "Build APK" تلقائياً (حوالي ٣-٥ دقائق).
4. لما يخلص ✅ افتحه ← تحت **Artifacts** نزّل `GearRemote-apk` ← فك الضغط ← بتلقى `app-debug.apk`.

## طريقة البناء (Android Studio)
افتح المجلد في Android Studio ← Build ← Build APK.

## التثبيت والتشغيل
1. انقل `app-debug.apk` للجوال وثبّته (وافق على "التثبيت من مصادر غير معروفة").
2. إذا الريموت مقترن في إعدادات البلوتوث وما اشتغل، **انسَه (Unpair)** من الإعدادات.
3. افتح التطبيق:
   - **١)** منح صلاحية البلوتوث.
   - **٢)** إعدادات إمكانية الوصول ← التطبيقات المثبتة ← Gear Remote ← تشغيل.
     - إذا الزر رمادي (أندرويد 13+): ارجع للتطبيق ← الزر الثالث ← في معلومات التطبيق اضغط ⋮ فوق ← **السماح بالإعدادات المقيدة**، ثم ارجع فعّل الخدمة.
4. اضغط زر Home في الريموت ضغطة وحدة عشان يصحى. بيظهر "✅ متصل وجاهز" وتشوف أرقام X/Y تتغير لما تلمس اللوحة.

## التحكم
| الريموت | الوظيفة |
|---|---|
| سحب للأعلى | الريل التالي |
| سحب للأسفل | الريل السابق |
| سحب يمين/يسار | تقليب الستوري |
| ضغط اللوحة | إيقاف/تشغيل |
| الزناد | لايك |
| + / − | الصوت (مطوّل = تكرار) |
| رجوع / بيت | رجوع / الشاشة الرئيسية |

إذا الاتجاه معكوس، شغّل "عكس اتجاه السحب" في التطبيق.

## مشاكل شائعة
- **يقول متصل بس الأرقام ما تتغير:** اضغط "إعادة الاتصال"، والتطبيق يرسل أمر التشغيل مرة ثانية تلقائياً كل ثانيتين.
- **ما يلقى الريموت:** تأكد إن البطاريات (AAA) شغالة واضغط Home، وتأكد إنه مو متصل بجهاز ثاني.
- **السحب يطلع زيادة أو ما يتحسس:** عدّل شريط "مسافة السحب".

البروتوكول مبني على الهندسة العكسية من مشروع jsyang/gearvr-controller-webbluetooth.
